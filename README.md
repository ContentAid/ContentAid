**Projects here**

- [xworth](https://github.com/devonburnedead/xworth): a browser extension that scores X posts from red to green. Scores come from an LLM judge first, which then gets distilled into a small local model that runs in about 20 ms per post. Lead scoring can use the same trick to keep costs down.
